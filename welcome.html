Welcome to AI Form Filler

Thank you for installing AI Form Filler! This extension helps you automatically fill web forms using AI (GPT or Claude). Let's get you set up in just a few steps.

Step 1: Get an API Key

This extension requires an API key from either OpenAI or Anthropic. If you don't have one already:

  • For OpenAI: Visit OpenAI Platform to create an account and generate an API Key.
  • For Anthropic: Visit Anthropic Console to create an account and generate an API Key.
Step 2: Configure the Extension

Enter your API key in the extension settings:

  1. Click on the extension icon in your browser toolbar
  2. Click the Settings link at the bottom
  3. Choose your preferred AI provider (OpenAI or Anthropic)
  4. Enter your API key and select the model
  5. Click Save Settings
Step 3: Start Using It

Once configured, using the extension is simple:

  1. Navigate to any webpage with a form
  2. Click on a form field you want to fill
  3. Click the extension icon to open the popup
  4. Select Fill Current Field or Fill All Fields
Note: All API calls are made directly from your browser to the AI service. Your API key is stored securely in your browser's extension storage and is never sent anywhere else.
